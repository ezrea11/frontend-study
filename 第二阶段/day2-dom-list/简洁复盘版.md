# Day 2 DOM 列表渲染与状态筛选复盘

##  今日功能点

后台用户列表渲染与活跃状态筛选功能。

## 核心思想

HTML 提供固定的 ul 容器，JavaScript 根据 users 数组动态创建 li，并插入 DOM 树中。

## 核心函数

renderUsers(list) 负责把传入的用户数组渲染到页面。

执行流程：

1. 清空旧列表：userList.innerHTML = ""
2. 遍历 list 数组
3. 每个 user 创建一个 li
4. 设置 li.textContent
5. appendChild 到 ul 中

## filter 的作用

filter 会返回一个新数组，不会修改原数组。

activeUsers 只包含 active === true 的用户对象。

##  按钮逻辑

Show All：调用 renderUsers(users)

Show Active Users：先 filter 得到 activeUsers，再调用 renderUsers(activeUsers)

## 小实验结论

如果去掉 userList.innerHTML = ""，多次点击按钮会导致 li 重复叠加。

所以 renderUsers 是重新渲染，不是继续追加。

## 项目意义

这个能力以后用于 React 中后台项目的 Users 用户列表页，包括列表展示、状态筛选、搜索筛选和分页前数据过滤。
